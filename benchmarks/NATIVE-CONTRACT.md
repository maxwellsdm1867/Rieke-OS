# Navigation probe handoff

The reusable `navigation-probe.mjs` exports canonicalJSON, canonicalRequest, attachLedger, temporalRequestSets and observeTransition. Import has no launch or service side effects. It was exercised in the bounded same-member restoration comparison. `sanitized-results.json` contains only aggregate/sample diagnostics and source commits. **The native first-slice release runner remains incomplete.** No turnkey fixture or Electron launcher is included.

## Adapter requirements

Supply paths, dynamically allocated origins/ports, immutable assets, an owned disposable profile, fixture identity, selectors and an independent authority validator through caller configuration. The probe requires a Playwright-compatible page. Never import private experiment scripts unchanged. The original runners contain local paths and native scientific identities and are local evidence only.

The fixture adapter must create synthetic or explicitly authorized disposable data, establish an independent membership/identity oracle, hash protected scientific tables before and after, and compare bounded raw H5 windows outside timing. Avoid bulk H5 copies. Allow only documented read operations; any tree-query POST must be explicitly read-only. The ledger captures exact API response bodies and request data: keep raw output private and emit an allowlisted sanitized summary.

Namespace complete request keys by project/path identity, backend incarnation and actor as applicable. Preserve method, complete query/body, splits, branches, pagination, generation and binding. Canonical JSON preserves array order; URL sorting preserves repeated-value order. Canonicalization alone is not an authority or cache-invalidation policy. A future cache track must permit independently validated current cache hits without forcing GET merely to satisfy the observer.

## Lifecycle and measurement

Confirm HTTP asset readiness before launching Electron. Record exact owned PIDs and parent identities. On any failed smoke, await graceful exit, then verify process absence before timed work. If bounded cleanup needs escalation, revalidate the exact owned process and descendants before terminating them; never broad-kill applications. Any leftover host disqualifies latency. Always close owned renderers, API and database in finally paths and save cleanup receipts even on failure.

Use immutable asset hashes, fresh profiles/scopes for defined cold visits, separately defined warm returns, a quiet runtime window, counterbalanced order and bounded repeated samples with raw distributions. Keep fault injection, H5 comparisons, hashing and forced GC outside timing. Retain scientific identity, current authority and protected-data gates before interpreting performance.

observeTransition takes page, locator, ledger, config, validateAuthority and relevantRequest. Caller supplies surfaceSelector and readySelector, and should supply loading, inert, layout-pane, selected and expanded selectors plus body-portaled blocking-modal selectors. A useful control alone does not establish authority. Its observed gates combine content, independently validated authority, relevant pending requests, stable layout and persistence; the caller must assert the intended restored state separately. Test child readiness explicitly. Request completion sets are temporal, not a causal waterfall. DOM/RAF observations do not establish compositor paint; use dedicated native instrumentation for that claim.
