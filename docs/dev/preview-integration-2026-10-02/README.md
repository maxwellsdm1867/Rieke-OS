Admission is a registered project of at most 10,000 epochs, a 64MiB scope, an 8MiB retained preview cache and a 32MiB retained operation budget; these are supported-size checks, not peak RSS or million-scale qualifications. Ordinary explicit-row selection retains its separate client limit. Incoming candidate group mutations remain unavailable.

The cumulative Workbench distinguishes proposal baseline B, frozen candidate C, current main M and actor draft. Explicit acceptance publishes M union selected(C minus B minus M), retaining existing main membership and curation. A previously committed operation recovers its receipt before source/proposal availability checks; interrupted acceptance must retry the same operation rather than creating another operation. New-only export is gated by its separate declared capability.

The MAIN overview must use its own unfiltered frozen-cohort protocol resource; browsing counts and pending distinct cell counts remain separately labelled. Missing pending counts stay unavailable rather than borrowing epoch or main counts. Candidate readers require exact scope authority and never substitute global readers.
