# Aggregate usage evidence and limits

The original read-only audit inspected a local recovery mirror and retained access
logs. Its raw personal presets, saved-query history, timestamps, actors and HTTP
records remain local. The public `usage.json` retains aggregate table counts,
observed field unions and limitations. `DEFAULTS.md` preserves proposed summary
defaults and scientific-priority additions.

The mirror held 41 current rows, including three tree layouts, one preset and ten
last-run records. These are saved-state counts, not deduplicated human actions.
Six older last-run rows retained no predicate. Access requests include refreshes
and automation; they cannot establish an 80-percent coverage claim. Protocol field
presence is scientific inventory, not operation frequency.

Routine query, preset and layout events are suppressed by `CurationStore._event`.
Reliable per-person query/split telemetry remains proposed. Browser summary
preferences are local to project/protocol/view and contain no person key.
The draft priority tiers (9 navigation, 7 scientific, 41 protocol-specific,
83 on-demand) are proposed policy, not an implemented field exclusion scheme.
All eligible fields and reconstruction dependencies remain available.
