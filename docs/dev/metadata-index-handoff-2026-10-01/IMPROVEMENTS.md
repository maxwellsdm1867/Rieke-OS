Checked 2026-10-01 against the archived final reports, work logs, model descriptions, measurement receipts and the earlier candidate commit. This supplements the summary so implementation details are explicit. It does not claim every prototype is integrated, that every improvement is independent, or that preserved behavior was newly implemented.

## Proposals explicitly not implemented

- Protocol-aware preferred summaries and user-pinned fields may grow from actual protocol parameters; no fixed28 schema is intended. The source registry already discovers eligible fields on import, but new protocol/type coverage still needs tests.
- Explicit deliberate-action logging, adaptive summary caching/precomputation and usage-triggered specialized indexes are future requirements. Current logs do not establish80% coverage.
- Broad exact counts/global aggregates need nonblocking, cancellable, generation-bound behavior and bounded caches. Remaining roughly3-second global summaries were not solved by the scoped fix.
- Production MySQL/source eligibility, generation-bound cursors, empty branches, live real tags, H5 reconstruction/export and all nine rendered actions remain integration gates.
