## Final workflow changes

- One selection toolbar serves normal incoming browsing and tree editing: Select all, Deselect all, View selected and Merge with the exact selected count.
- Focusing an epoch or cell does not select it for publication. Merge and Export use explicit selected UUIDs. A selection with excluded epochs is refused before draft writes; unreviewed epochs require explicit review. A fresh preview and separate confirmation precede acceptance into Main.
- Complete selection uses frozen scoped pages, including pages beyond the visible page. Explicit selections remain limited to 1,000 epochs, with stale-scope, duplicate and incomplete-count checks.
- Tree controls separate Select from Tag. Cell tags, direct epoch tags and explicit downstream epoch tags keep distinct targets. Selecting multiple epochs retains the focused waveform and metadata.
- Uncertain acceptance/export operations retain their existing operation identities and receipt-recovery behavior. No backend, schema or dependency changes are part of the final UI commit.
